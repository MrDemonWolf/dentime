## Context

The repository was reset to two files and rebuilt from scratch on 2026-08-06. The old stack — Cloudflare Workers, Hono, Drizzle, D1, Better Auth, and a local-only MVP1 SwiftUI app — is dead. **CloudKit is now the entire backend.**

Everything is scaffolding. There is no feature UI, and that is deliberate.

### 3. Dependabot — mostly handled

Three of four are merged and `main` is green with all of them: GitHub Actions ×6 (#4), `@types/node` 26 (#6), and **fumadocs-mdx 15** (#3, a major — it needed no `source.ts` changes after all).

**Still open: #5, TypeScript 5.9.3 → 7.0.2.** Genuinely broken, not a flake. TypeScript 7 removed the `baseUrl` option and `apps/docs/tsconfig.json` sets it, so typecheck dies with `TS5102`. The fix is one deleted line — the `paths` entries are already `./`-prefixed and resolve relative to the tsconfig without it — but TS 7 is the Go-native rewrite and Next 16 plus fumadocs have not been widely exercised against it. It is a dev dependency; nothing ships with it. Awaiting a decision.

#### One specific Dependabot failure is a false alarm — check before assuming

Dependabot often bumps `package.json` but writes a `bun.lock` that does not satisfy it. CI runs `bun install --frozen-lockfile`, which correctly refuses, and every step after it fails. That looks like a broken upgrade and is not one.

**Confirm it is this before reaching for the fix.** The signature is the install step itself failing with:

```
error: lockfile had changes, but lockfile is frozen
```

If the install succeeds and something later fails, the upgrade is genuinely incompatible — that is what happened to TypeScript 7 above, which died at typecheck with `TS5102`, not at install. Regenerating the lockfile would not have saved it, and doing so blindly would have buried a real incompatibility.

Fix, once you have confirmed the frozen-lockfile signature:

```bash
gh pr checkout <n>
bun install          # regenerates bun.lock
git commit -am "chore(deps): regenerate bun.lock" && git push
```

Do not "fix" this by dropping `--frozen-lockfile` from CI — that flag is what stops a bad lockfile reaching `main`.

### Two gotchas if you automate against Jira again

- **Never write `&amp;` into a summary.** The API stores the literal entity rather than an ampersand. Write a plain `&`.
- **A malformed API response does not mean the write failed.** During the board build, two mutating calls came back as an empty search-shaped payload while having actually succeeded. Read back before retrying, or you will create duplicates.

## Things not to re-litigate

These were decided, some of them twice. `docs/planning/DECISIONS.md` is the source of truth and wins over every other document.

- No EventKit. No StoreKit. No server. CloudKit only.
- No push invites and no notifications. Meetups are join-by-code.
- No meetup titles or descriptions, ever.
- Paid up front at $9.99. No free tier, no trial.
- Bundle ID `com.mrdemonwolf.dentime` on every platform target, no suffix. Universal Purchase cannot be retrofitted after launch.
- Docs on GitHub Pages, no custom domain.
- The Den is the default tab. Time Peek is a scrubber inside it, not a tab.
- Blocking copy says "You won't see them", never "They can't see you".
