## Context

DenTime is a $9.99 paid macOS menu bar app. It keeps a roster of your people ("your den"), shows their local time, and runs Doodle-style polls to pick a time that works for everyone. It is built for friend groups, not corporate teams.

The repository was reset to two files and rebuilt from scratch on 2026-08-06. The old stack — Cloudflare Workers, Hono, Drizzle, D1, Better Auth, and a local-only MVP1 SwiftUI app — is dead. **CloudKit is now the entire backend.**

Everything is scaffolding. There is no feature UI, and that is deliberate.

## Next steps

### 1. Verify the Xcode project — do this first

```bash
brew install xcodegen
cd apps/apple && USER=$(whoami) xcodegen generate && open DenTime.xcodeproj
```

The `USER=` prefix works around XcodeGen reporting "Couldn't find current username" in some shells.

Then confirm:

- [ ] The project opens without errors
- [ ] `DenTimeCore` resolves as a local package dependency
- [ ] The target builds with **zero warnings**
- [ ] Bundle ID is `com.mrdemonwolf.dentime` with **no suffix**
- [ ] Running it puts an icon in the menu bar with no Dock icon, and the popover shows "DenTime"

If `project.yml` needs fixing, fix it there — never hand-edit the generated `.xcodeproj`, which is gitignored.

You will need to set `DEVELOPMENT_TEAM` in `apps/apple/Config/Shared.xcconfig`; it is deliberately blank so a clean clone builds without signing setup.

## Open questions / blockers

Full list in `docs/planning/OPEN-QUESTIONS.md`. The ones that will actually bite:

- **CloudKit schema versioning is unsolved.** The schema lives in a dashboard, not in git, and dev→prod is a manual promote. Nothing in the repo can verify the deployed schema matches the code.
- **Host results view at 360pt.** Six participants × five slots does not fit as a literal grid in a menu bar panel. No answer yet, and the mockup does not settle it. Blocks the tail of phase 10.
- **App Store name not checked** against existing listings. Also: do not lead the title with "Meetups" — Meetup.com holds that trademark.
- **Two design review findings still open** — the undo toast for Remove, and unverified accessibility (focus rings, VoiceOver, live regions). Both are SwiftUI-build obligations.

## Things not to re-litigate

These were decided, some of them twice. `docs/planning/DECISIONS.md` is the source of truth and wins over every other document.

- No EventKit. No StoreKit. No server. CloudKit only.
- No push invites and no notifications. Meetups are join-by-code.
- No meetup titles or descriptions, ever.
- Paid up front at $9.99. No free tier, no trial.
- Bundle ID `com.mrdemonwolf.dentime` on every platform target, no suffix. Universal Purchase cannot be retrofitted after launch.
- Docs on GitHub Pages, no custom domain.
- The Den is the default tab. Time Peek is a scrubber inside it, not a tab.
- Blocking copy says "You won't see them", never "They can't see you".
