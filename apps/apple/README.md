# apps/apple

The Xcode project. **This directory is not part of the Turborepo build graph and is not a Bun workspace.** Xcode builds it; `turbo build` never touches it.

## Generating the project

`DenTime.xcodeproj` is generated by [XcodeGen](https://github.com/yonaskolb/XcodeGen) from `project.yml` and is gitignored. Never hand-edit the project file — edit `project.yml` and regenerate.

```bash
cd apps/apple && USER=$(whoami) xcodegen generate && open DenTime.xcodeproj
```

The `USER=` prefix works around XcodeGen reporting "Couldn't find current username" in some shells. Install it with `brew install xcodegen`.

## Building

```bash
xcodebuild -project DenTime.xcodeproj -scheme DenTimeMac -destination 'platform=macOS' build
```

## Layout

```
project.yml                     source of truth for the project
Config/Shared.xcconfig          version, team, warnings — shared by every future target
Config/DenTimeMac.xcconfig      bundle ID, product name, asset catalog
DenTimeMac/DenTimeMacApp.swift  MenuBarExtra scene and the placeholder root view
DenTimeMac/Info.plist           LSUIElement, versions, export compliance
DenTimeMac/DenTimeMac.entitlements
DenTimeMac/Resources/           asset catalog and the privacy manifest
```

## Rules this target holds to

- **Bundle ID is `com.mrdemonwolf.dentime` with no suffix**, on this and every future platform target. Different IDs per platform sell as separate $9.99 products and break Universal Purchase permanently. Only a future watch target gets a suffix, because Apple requires `.watchkitapp`.
- **No EventKit, no StoreKit**, and no contacts, location, camera or microphone entitlements. Calendar integration and in-app purchases are both out of scope, and both are pass conditions in the definition of done.
- Menu bar only — `LSUIElement` is true, so there is no Dock icon and no window on launch.
- App Sandbox and Hardened Runtime are on; the only network capability is `com.apple.security.network.client`, which CloudKit needs.

## What is not here yet

Everything. The root view is a single `Text("DenTime")` on purpose. The Den tab, Time Peek scrubber, Meetups and the Settings window are phases 6–11 in `docs/planning/PHASES.md`, and the mockup they are built from is in `docs/design`.
