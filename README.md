# DenTime - Time Zones for Your Pack

DenTime is a macOS menu bar app that keeps a roster of the people you
care about, shows you their local time at a glance, and runs
Doodle-style polls so a group spread across four time zones can settle
on a night that works. It is built for friend groups first - movie
night, raid night, a con meetup - rather than for corporate calendars,
and a Vocabulary setting swaps seven nouns for anyone who wants to use
it at work.

Stop doing time zone maths in your head. Just pick a night.

## Features

- **Your den, at a glance** - Person rows showing name, local time,
  time zone and day of the week. The day is on every row, because
  turning up on the wrong evening is the failure mode this app exists
  to prevent.
- **Packs** - Collapsible groups you drag people between. A pack named
  "Acme Corp" behaves exactly like one named "the boys".
- **Time Peek** - A scrubber at the top of the Den. Drag it and every
  time updates live. Fully client-side; it never touches the network.
- **Meetups** - Propose two to five slots, get a join code, paste it
  wherever your pack already talks. Everyone sees the slots in their
  own local time and answers yes, no or maybe.
- **Join by code, never by push** - Nobody can reach you without you
  entering their code. There are no invitations and no notifications
  of any kind.
- **Friend codes you can rotate** - Eight Crockford base32 symbols,
  generated on device. Rotating one genuinely invalidates the old.
- **Your data stays in your iCloud** - CloudKit is the entire backend.
  There is no DenTime server, no account database and no analytics.
- **Den or Team wording** - One setting swaps seven nouns. The voice,
  the buttons and the tone stay exactly the same.

## Getting Started

DenTime is in development and is not yet on the App Store. Planning
documents live in `docs/planning`, and the current state of the build
is tracked in `docs/planning/PHASES.md`.

Documentation site: https://mrdemonwolf.github.io/dentime

To work on the repository:

1. Install Bun 1.3 or newer and Node 20 or newer.
2. Clone the repository and run `bun install`.
3. Run `bun run dev` to serve the documentation site on port 3001.
4. On a Mac, install XcodeGen with `brew install xcodegen`, then run
   `cd apps/apple && USER=$(whoami) xcodegen generate` to produce
   `DenTime.xcodeproj`.
5. Run `swift test --package-path packages/DenTimeCore` to check the
   shared Swift package.

## Usage

The two surfaces of the app, and what each one is for:

| Surface | What it does |
| --- | --- |
| Den tab | Opens here. Roster, packs, Time Peek scrubber, add and block people. |
| Meetups tab | Create a poll over two to five slots, or join one with a code. |
| Settings window | Opened with Command-comma. General, Account, Blocked, About. |

Codes DenTime hands out:

| Code | Format | What it is for |
| --- | --- | --- |
| Friend code | `DEN-XXXX-XXXX` | Share it so someone can add you to their den. |
| Join code | `HOWL-XXXX-XXXX` | Share it so people can join one meetup. |

Both use a 32-symbol Crockford base32 alphabet with `I`, `L`, `O` and
`U` removed, so a code read aloud or retyped cannot be confused with a
digit.

## Tech Stack

| Layer | Technology |
| --- | --- |
| macOS app | SwiftUI, `MenuBarExtra`, macOS 14 or newer |
| Shared logic | `DenTimeCore`, a Swift package with no third-party dependencies |
| Backend | CloudKit - public, private and shared databases |
| Identity | Sign in with Apple |
| Xcode project | Generated by XcodeGen from `apps/apple/project.yml` |
| Documentation site | Next.js and Fumadocs, static export |
| Styling | Tailwind CSS v4 |
| Monorepo | Bun workspaces and Turborepo |
| Linting and formatting | Biome |
| Hosting | GitHub Pages |
| CI | GitHub Actions |

There is deliberately no server, no database and no third-party
service beyond Apple's own. The reasoning for each choice is recorded
in `docs/planning/DECISIONS.md`.

## Development

### Prerequisites

- Bun 1.3.14 or newer
- Node 20 or newer
- macOS 14 or newer, for anything involving the app itself
- Xcode 15 or newer
- XcodeGen, installed with `brew install xcodegen`

The TypeScript side runs anywhere. The Swift side needs a Mac.

### Setup

1. Clone the repository.

```bash
git clone https://github.com/MrDemonWolf/dentime.git
cd dentime
```

2. Install dependencies.

```bash
bun install
```

3. Start the documentation site.

```bash
bun run dev
```

4. Generate and open the Xcode project, on a Mac.

```bash
cd apps/apple && USER=$(whoami) xcodegen generate && open DenTime.xcodeproj
```

The `USER=` prefix works around XcodeGen reporting "Couldn't find
current username" in some shells.

5. Build and test the shared Swift package.

```bash
swift test --package-path packages/DenTimeCore
```

### Development Scripts

- `bun run dev` - Serve the documentation site on port 3001.
- `bun run build` - Build the documentation site for static export.
- `bun run typecheck` - Type-check every TypeScript workspace.
- `bun run test` - Run the TypeScript test tasks.
- `bun run lint` - Run Biome's linter.
- `bun run format` - Format with Biome, writing changes.
- `bun run format:check` - Check formatting without writing.
- `bun run check` - Run Biome's linter, formatter and import sorting.
- `bun run check:fix` - The same, applying every safe fix.
- `bun run clean` - Remove build output and caches.

Swift work is driven by `swift build` and `swift test` against
`packages/DenTimeCore`, or by Xcode for the app target.

### Code Quality

- Biome for linting, formatting and import sorting, with tabs and
  double quotes enforced through `.editorconfig`.
- TypeScript in strict mode. `any` is not permitted.
- XCTest for the Swift package, with the time zone tests written
  against real daylight saving transitions rather than mid-season
  samples.
- Conventional commits.
- CI runs Biome, type-checking and the docs build on Linux, the Swift
  package build and tests on macOS, and scope guards that fail the
  build if EventKit, StoreKit or a server dependency reappears.

## Project Structure

```
dentime/
  apps/
    apple/              Xcode project - outside the Turborepo graph
      project.yml       XcodeGen source of truth
      Config/           Shared and per-target xcconfig files
      DenTimeMac/       macOS menu bar target
    docs/               Fumadocs documentation site
      content/docs/     MDX pages
      src/app/          Routes, layouts and theme
  packages/
    DenTimeCore/        Swift package - outside the Turborepo graph
      Sources/          Models, TimeMath, CloudKit, Codes, Vocabulary
      Tests/            XCTest suites
  docs/
    design/             v2 mockup and UI/UX review, reference only
    planning/           Decisions, spec, phases, Apple checklist, backlog
      archive/          Superseded planning material, kept on purpose
  assets/               Brand marks
  .github/              Workflows, templates, CODEOWNERS
```

`apps/apple` and `packages/DenTimeCore` are deliberately excluded from
the Bun workspace globs and from Turborepo's pipeline. Xcode builds
them; `turbo build` never touches them. Running `bun run build` will
not produce a Mac app, and it is not meant to.
